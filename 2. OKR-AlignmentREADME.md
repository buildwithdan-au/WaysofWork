# Weekly OKR Alignment Report

A Glean agent that maps a week of your work activity to your personal OKRs, writes a weekly narrative report as a Google Doc, and appends a structured row to a quarterly Google Sheet log.

- **Agent:** [Weekly OKR Alignment Report](https://app.glean.com/chat/agents/ff811c994ad64b108fc9270529b2f660)
- **Owner:** Dan McHugh, Senior Commercial Manager, Revenue Operations

---

## What it does

1. **Collects** the past 7 days of activity from Drive, Email, Calendar, Slack and Jira.
2. **Loads OKR context** from your personal OKRs doc, with backup OKRs if any goals are still placeholder text.
3. **Maps** each activity to an OKR and Key Result, with a "so what" contribution statement and a confidence rating.
4. **Selects** the top 3 contributions of the week.
5. **Flags** anything that can't be clearly mapped as a Watch Item (never discarded).
6. **Writes** the report to a new Google Doc using a fixed template.
7. **Logs** a structured row to the quarterly Google Sheet.
8. **Posts** a short completion summary with links.

## Pipeline

| Step | Purpose | Output |
|---|---|---|
| Drive / Email / Calendar / Slack / Jira Activity | Gather the last 7 days of activity per source | Raw activity lists |
| OKR Mapping | Load OKRs, consolidate activities, map, pick top 3, flag watch items, write 2-sentence summary | Analysis held in memory (no formatted output) |
| Report | Fill the report template | Report text |
| Create Google Doc | Publish the report | Google Doc link |
| Quarterly log | Append a structured row | Google Sheet link |
| Completion summary | Report what was produced | Chat message |

## OKR context

Primary source: your personal **My OKRs** doc.

If a goal looks like placeholder text, the agent falls back to these objectives from Rich Shank's GSO FY26 OKRs:

| OKR | Objective | Key results used |
|---|---|---|
| O5 | Drive Payments revenue | KR1 Revenue growth, KR3 New payment orgs |
| O10 | Deepen AU | KR2 Partner channel growth, KR3 Product mix via BE & multi-product |
| O11 | PXL / Transform partner sales channel | KR1 High value partners, KR3 Better BE mix, KR4 Partner program incentives, KR5 Sales effectiveness |
| O14 | Seamless delivery in a matrix | KR1 Optimise regional/functional model |

## Activity mapping format

Each activity is recorded as:

```
Activity:     [title/description]
Source:       [Drive / Email / Calendar / Slack / Jira / Miro / Asana]
OKR:          [O-number and name]
Key Result:   [KR number and name]
Contribution: [1-2 sentences on how it moves the KR]
Confidence:   [High / Medium / Low]
```

## Report template

1. Title, name and role, week-ending date
2. 📝 Week Summary (2 sentences)
3. 🏆 Top 3 Contributions (OKR, Key Result, Contribution each)
4. 📋 All Activities Mapped to OKRs (table)
5. ⚠️ Watch Items (or "None this week.")
6. 📊 OKR Coverage (activity counts for O5, O10, O11, O14, Other)

## Usage

1. Run the agent in Glean (manually, or on a weekly schedule at end of week).
2. Open the Google Doc link from the completion message.
3. Review **Watch Items**. They may signal work that needs an OKR home, or OKRs that need updating.

## Known gaps

- **Quarterly log:** In the 6 Nov 2026 run, the Google Doc was created but the agent reported no Sheet link, so it couldn't confirm the log was updated. Check the Sheet after each run.
- **Miro and Asana:** Allowed as sources in the mapping format, but there are no gather steps for them.
- **Hard-coded user:** The prompt names Dan McHugh and his role. Change these to reuse the agent for someone else.
- **Fallback OKRs:** Backup OKRs reflect FY26 and will need refreshing for the next fiscal year.
- **Results are permission-filtered:** Empty results can mean no access, not no activity.
