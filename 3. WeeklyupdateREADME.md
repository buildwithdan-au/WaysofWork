# Weekly Status Update

Automatically reviews the past 7 days of work across Asana, Slack, and Gmail and drafts a short status update.

## What it does

| Source | What's pulled | Used for |
|---|---|---|
| Asana | Tasks completed or open in the window | Completed, In Progress, Open |
| Slack | Dan's messages across channels and DMs | Decisions, deliverables, commitments |
| Gmail | Sent threads | Pre-reads, notes, meetings held or scheduled |

Output is a structured draft: Completed, In Progress, Decisions / Alignment, Open / Needs Follow-through, Next Week. It is capped at 12 bullets.

## Schedule

| Setting | Value |
|---|---|
| Task ID | `weekly-status-draft` |
| Cadence | Fridays, 4:30 PM local |
| Cron | `30 16 * * 5` |
| Location | `~/Documents/Claude/Scheduled/weekly-status-draft/SKILL.md` |

Scheduled tasks run only while the Claude app is open. If it's closed at the scheduled time, the task runs on next launch.

## Usage

- **On demand:** ask "run my weekly status update" or "what did I do this week".
- **Scheduled:** runs automatically each Friday and posts the draft to the session.
- **First run:** click **Run now** in the sidebar's Scheduled section to pre-approve connector permissions so later runs don't pause for prompts.

## Requirements

Connectors: Asana, Slack, Gmail.

## Customising

| Change | Edit |
|---|---|
| Day or time | `cronExpression` on the scheduled task (use `update_scheduled_task`) |
| Lookback window | "Inputs" and Gmail `newer_than` in `SKILL.md` |
| Sections or bullet cap | "Output format" and "Synthesis rules" in `SKILL.md` |
| Add a source | Add a pull under "Steps" (e.g. Google Drive, Calendar) |

## Known limitations

- Slack search returns the 20 most recent messages per page. Very busy weeks may need a second page.
- Gmail results include calendar noise. The skill filters it, but meeting-heavy weeks may under-report email substance.
- Asana tasks with no due date or project are surfaced only when clearly active. Duplicate deal-approval tasks are flagged rather than merged.
- The draft is not sent anywhere. Dan reviews and forwards it.
